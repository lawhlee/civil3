# 민법3 · 9월·10월 시험연습실

9월 29문항과 10월 30문항, 총 59문항을 학습하는 정적 웹사이트입니다.

## 문제와 해설

- 원문 객관식, 개념 O/X, 사례변형(실험), 모의시험, 오답노트, 북마크를 제공합니다.
- 지문 262개 모두에 해설과 근거 발췌문이 있습니다. 강의안 인용 271개와 보충 판례·조문 인용 45개를 해설 화면 안에 표시합니다.
- 전체 지문의 해설과 변형을 강의안·공식 판례에 대조했습니다. 판단 전제나 적용 시점이 불명확한 변형은 출제에서 제외하며, 일반 출제에는 개념 변형 131개를 제공합니다. 사례 변형 26개 유형은 **사례변형(실험)**을 선택할 때만 출제하며, 오답노트·북마크에서도 별도로 선택합니다. 기존에 검토 후 제외한 변형은 실험 항목에서도 제공하지 않습니다.
- 강의안 쪽수와 판례번호를 출처로 표시하며, 보충 판례·조문은 구분합니다.
- 원문 문제와 월별 제공 답안표를 사이트 안에서 읽을 수 있습니다. 모의시험 중에는 답안표를 표시하지 않습니다.
- 10월 5번의 ㄹ은 대법원 1995. 3. 28. 선고 93다47745 전원합의체 판결의 다수의견에 따라 X로 해설합니다. 정답은 ③만 인정하며 ②는 오답입니다. 이 문항은 원문 객관식으로 연습합니다.
- 현재 게시 파일에는 PDF가 포함되지 않으며, 외부 PDF를 열지 않아도 문제와 해설을 읽을 수 있습니다.

## 학습 지도

- 첫 화면은 9월·10월 전체 59문항의 풀이 경험을 원형 그래프와 주요 주제별 막대로 표시합니다.
- 학습 지도의 **통계 범위**에서 월을 직접 고르면 해당 월의 통계를 표시합니다. 이 선택은 연습할 문제 세트 설정과 별도로 관리됩니다.
- 한 번 이상 채점한 원문 수는 O/X·변형을 포함하되, 같은 원문은 중복 집계하지 않습니다.
- 아직 안 푼 원문과 복습할 항목 수를 표시하며, 주제 막대를 누르면 지도에서 보고 있는 세트와 해당 주제가 연습 범위로 선택됩니다.
- 기록이 없으면 0부터 표시합니다. 풀이 경험은 정답률이나 숙련도를 뜻하지 않습니다.

## 모바일 사용

- 좁은 화면에서는 메뉴·설정·문항 번호판을 화면 폭에 맞추어 배치합니다.
- 주요 버튼의 터치 영역, 지문·해설 글자 크기, 입력 글자 크기를 조정했습니다.
- 상단의 **학습 기록 관리**에서 모바일에서도 백업과 가져오기를 할 수 있습니다.
- 자료 팝업은 화면 높이와 안전 영역에 맞추며, 열려 있는 동안 배경 스크롤을 잠급니다.

## GitHub Pages 게시

1. [Pages 설정](https://github.com/lawhlee/civil3/settings/pages)을 엽니다.
2. Source에서 **Deploy from a branch**를 선택합니다.
3. **main** 브랜치와 **/(root)**를 선택하고 Save를 누릅니다.
4. 배포가 완료되면 https://lawhlee.github.io/civil3/ 로 접속합니다.

별도 빌드 명령이나 서버, API 키가 필요하지 않습니다. HTML·CSS·JS는 상대 경로를 사용하고 `.nojekyll`을 포함합니다.

## 학습 기록

학습 기록은 브라우저에 저장됩니다. 해설·채점 기준이 변경된 기록은 다시 확인할 항목으로 표시하며, 해당 문항의 회차 응답은 초기화합니다. 검토 후 제외한 변형은 저장된 회차·북마크·오답노트에서도 제거하되, 과거 회차 이력과 누적 횟수는 보존합니다. 기존 사이트에서 **학습 기록 관리 → 백업 내려받기**를 실행한 다음 새 사이트의 **백업 가져오기**로 이전할 수 있습니다. 사이트 주소가 달라지면 자동으로 이전되지는 않습니다.

기존 사이트: https://civil3-september-drill.hslee0251.chatgpt.site/

## 변호사시험 기출 출처

- 원문과 완전히 동일한 33문항의 해설에는 변호사시험 회차·연도·문제번호와 **기출 동일**을 표시합니다.
- 보기·사실관계가 변경된 6문항과 문장·안내문 표현만 달라진 10월 3·4번에는 **기출 변형**과 변경 내용을 표시합니다.
- O/X·사례변형과 선택지 순서를 섞은 문제에는 해당 재구성 방식도 표시합니다. 기출 출처는 바탕 연습문제 기준입니다.
- 일부 지문만 겹치는 문항은 전체 문제의 출처로 단정하지 않습니다. 출처 대조 데이터는 `exam-sources.js`에 있습니다.
