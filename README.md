# 민법 III 연습문제

공동소유와 부동산 명의신탁을 다루는 연습 사이트입니다.

[연습 사이트 열기](https://lawhlee.github.io/civil3/)

- 원문 33문항은 개념형 15문항과 사례형 18문항으로 구성되어 있습니다.
- 개념형은 원문 객관식 또는 선지별 O/X로 풀 수 있습니다. 세트 설정에서 변형문제 포함 여부를 선택할 수 있습니다.
- 사례형은 사실관계와 선지를 함께 제시하는 원문 객관식으로 풉니다.
- 채점 전후에 이전·다음 문제로 이동할 수 있습니다. 선택한 답과 학습 기록은 해당 브라우저에 저장됩니다.

`main` 브랜치의 루트에서 GitHub Pages로 배포합니다.
